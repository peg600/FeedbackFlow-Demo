# 0021 — 首页按会话展示账户入口

- 状态：Accepted
- 记录日期：2026-10-11
- 决策日期：2026-10-11
- 记录性质：当次记录
- 替代：无，扩展 ADR 0001 与 ADR 0020
- 被替代：无

## 背景与约束

统一 Header 只配置静态首页入口，登录后的用户仍看到登录链接。用户要求首页去掉 Header 中的功能和价格入口，按登录状态展示账户操作；已登录时，退出应像控制台的小型次要按钮一样位于最右侧。首页及其正文仍须对所有访问者开放，不能把会话查询、资源授权或数据库依赖耦合到共享展示组件中。

## 考虑过的方案

| 方案 | 优点 | 成本与限制 | 取舍理由 |
| --- | --- | --- | --- |
| 首页服务端读取 Session，再传给 Header | 首屏可直接给出确定身份 | 首页正文渲染依赖认证数据库与会话读取可用性 | 不采用 |
| 在 SiteHeader 中读取会话 | 所有调用点自动获得账户状态 | 共享组件承担认证编排，给不需要账户入口的页面增加查询 | 不采用 |
| 首页专属客户端组合读取官方 Session，复用 SiteHeader | 限定查询范围，公开正文独立渲染，保留统一视觉 | 需明确等待和查询失败状态 | 采用 |

## 决策与理由

- `HomeHeader` 使用已有 `authClient.useSession()`，只决定账户入口展示，不构成资源授权。所有受保护页面和写操作继续服务端验证真实 Session。
- 已登录使用原 `SignOutButton compact`，保留退出并发保护、安全错误映射、失败可见提示与成功导航；未登录显示小型次要登录链接，并保留创建反馈板入口。
- 初次会话查询等待时显示有可访问名称的占位，不能把未知身份当作未登录。查询失败时显示本地双语安全提示及重试入口；重试抛出异常也有可见反馈，不展示原始异常。
- 共享 `SiteHeader` 新增 `trailingAction` 展示插槽，位于普通导航和移动菜单之后。首页账户入口使用该插槽，在桌面和移动端均只挂载一份并保持最右侧；既有页面的业务操作插槽不受影响。
- 首页 Header 只保留控制台、作者和语言相关入口，移除功能/价格链接；正文对应章节和页脚链接继续保留。
- 同轮展示微调：选中语言复用更深的品牌色与稍粗字重，保持无背景；控制台 Header 去掉品牌列右侧竖线，保留侧栏对齐及横向连续背景。

## 影响与代价

- 首页增加浏览器端官方会话请求；初始账户入口是等待状态，正文不等待该请求。
- 认证服务暂不可用时，账户区域显示安全错误和重试，公共内容仍可浏览。
- 未新增依赖、API、数据库字段、迁移、环境变量或认证策略；不读取原始 Cookie、客户端 Secret 或自行推断身份。

## 实施与验证

已实现客户端首页组合、最右侧共享插槽及展示微调。新增 10 项组件测试，覆盖匿名、登录、等待、后台读取失败、读取失败重试与重试异常、重试期间禁用、退出失败安全提示及中文展示；已登录退出入口只挂载一份，且不依赖移动菜单展开。

本轮实际验证：`pnpm lint`、`pnpm typecheck`、`git diff --check` 和 Production build 通过；全量单测 57 个文件、308 项全部通过。构建使用一次性进程内认证 Secret 与 localhost 占位数据库地址，不修改环境文件，不代表真实生产配置已验收。

匿名英文/中文首页 HTTP 请求均返回 200，服务端首屏包含会话等待占位，Header 不含功能/价格链接，正文对应章节仍保留。独立只读安全审查未发现身份、授权、错误泄露或 Server/Client 边界阻断问题。真实浏览器连接仍不可用，本轮没有操作真实账号登录或退出，亦未声称已完成真实视口视觉检查。

## 重新评估条件

需要无等待的账户首屏、更多页面使用身份导航或实际测得会话请求开销明显时，重新评估会话读取位置与请求复用；不得用客户端导航状态替代服务端权限验证。
