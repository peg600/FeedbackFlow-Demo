# 0025 — 首页 Demo 导览与标签页内关闭记忆

- 决策日期：2026-10-22
- 记录性质：当次记录
- 替代：无
- 被替代：无

## 背景与约束

用户要求首页弹窗友好介绍 Demo 的用途、技术与业务体验流程。已有公开反馈板、Owner 控制台、登录页演示凭据与 Paddle Sandbox；导览仅说明并链接这些现有能力，不新增账号、接口或业务写操作。首页保持 Server Component，交互由最小客户端组件承接。

## 考虑过的方案

| 方案 | 优点 | 成本与限制 | 取舍理由 |
| --- | --- | --- | --- |
| 每次访问都弹出 | 容易发现 | 返回首页时反复打断体验 | 不采用 |
| 仅手动打开 | 不打断浏览 | 初次访问者容易错过 | 保留为重新打开入口 |
| 首次自动打开，sessionStorage 记录关闭 | 引导首次体验，同一标签页内不重复打扰 | 新会话会再次展示，存储受限时无法记忆 | 采用 |

## 决策与理由

- 新增首页专用 `DemoGuide`，复用现有 `radix-ui` Dialog 与语义 Token，不安装依赖。Portal、焦点约束、Escape 关闭、背景锁定与触发器焦点恢复由原语提供；打开时焦点落在标题，便于从头阅读。
- 服务端与客户端首帧保持关闭，在客户端挂载后的动画帧读取 `feedbackflow-demo-guide-dismissed-v1`，未关闭过则自动打开。取消挂载时清理待执行帧，避免迟到回调。
- 用户通过关闭按钮、Escape、遮罩或体验链接关闭时写入 `1`。手动入口始终可用。存储读取/写入失败不阻塞关闭或导航；此时重新挂载可能再次弹出，不承诺跨设备记忆。
- 内容按访客浏览、登录提交/投票、Owner 管理与路线图同步、Sandbox 订阅分为四步；技术信息可展开。弹窗内提供语言切换，遵循 ADR 0019，刷新时保留当前弹窗状态。
- 体验入口仅使用现有 `/p/demo` 与受保护的 `/dashboard`。后者由既有服务端边界处理登录与项目引导，不绕过认证或暴露凭据。明确演示工作空间共享、Free 额度来自既有常量、支付仅 Sandbox，外部配置决定可用性。
- 面板使用视口内最大高度及内部纵向滚动，以支持手机和矮视口。视觉采用 Figma `12:376` 与现有 `globals.css`；本地 `docs/design-system.md` 缺失，不新增 Token 或改写设计文件。

## 影响与代价

- 首次访客获得操作路线，关闭后仍能自行重新查看。
- 新增客户端弹窗交互与一个不含身份信息的 sessionStorage 标记，无数据库迁移、环境变量、业务缓存或部署配置变更。
- 自动弹窗需要 JavaScript；未启用时原首页与导航仍可使用。
- 导览需随业务流程与技术栈变化维护双语文案。

## 实施与验证

已实现组件、首页入口、中英文文案及自动打开/关闭记忆、语言切换、存储异常测试。本次验证：

- 全仓库 lint、typecheck 通过；导览、首页、双语页面和首页 Header 共 31 项相关测试通过。
- 本地 Playwright 检查中英两种语言、9 种宽度与 3 种高度共 54 组布局；技术栈展开后面板保持在视口内，无横向溢出，矮屏允许纵向滚动。
- 真实浏览器验证 Tab 焦点约束、Escape/遮罩关闭、触发器焦点恢复、刷新及跳转返回后的关闭记忆、弹窗内语言切换与反馈板入口，无页面运行错误。控制台入口验证匿名访问跳转登录。
- 独立只读审查未发现待修复问题。未新增路由、依赖或构建配置，未执行生产构建与部署；此次验收不代表云端配置或支付全链路已完成。

## 重新评估条件

需要跨设备记忆、账号级新手任务、更多页面的引导或导览内容版本强制重展时重新评估。
